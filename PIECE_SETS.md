## Extraction

The sheets are laid out three different ways, so a single grid split would have
clipped pieces. Each was segmented by **actual empty gaps** — fixed columns,
then vertical gaps within each column — which handles the staircase arrangement
in Fae where rows overlap vertically.

For Fae I assign colours by **measured luminance** rather than by row order, so
a re-exported sheet with the rows swapped cannot silently invert the set.

Each piece is trimmed to its own bounding box, then centred on a 128×128 canvas
with uniform padding. Without that, pieces sit at different heights on the board
and the set looks unsteady.

## Contrast rims

Monochrome art has a real problem: a white piece is invisible on a light square
and a black piece disappears on a dark one. Real piece sets solve this with an
outline, so each piece gets a rim — dark behind white pieces, light behind black
— by dilating the alpha channel and filling it behind the artwork. Verified
against both square colours before shipping.

## How it hooks up

Chessground renders `<piece class="white king">` and paints it with a background
image, so a set is a **stylesheet**, not a component. `pieceSetCss()` in
`BoardThemeStyles.tsx` generates twelve rules per set. Fontaine emits nothing,
leaving the library default in place.

Old accounts holding the retired keys (`classic`/`modern`/`minimal`) fall back
to Fontaine rather than resolving to a set that does not exist.

## Adding board vectors

Yes — send them and I will wire them as themes. Two things worth knowing.

Board themes are currently two hex colours per theme, applied as a CSS
`background` on `cg-board`. A vector board is a different mechanic: one image
tiled or stretched across the whole board, which means the `BOARD_COLORS` map
becomes a discriminated union of *colour* themes and *image* themes.

What works best as source art:

- **One repeating 2×2 tile** — best result by far. Scales to any board size with
  no resampling, and stays crisp on a phone.
- A full 8×8 board image also works, stretched to fit; slightly softer at small
  sizes.
- Avoid pre-baked coordinates or borders in the art — Chessground draws its own,
  and they will not line up.

Anything with a distinct light and dark square colour I can also extract into a
plain colour theme automatically, so you would get both variants from one file.
